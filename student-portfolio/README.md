# Student Portfolio

This portfolio app has been enhanced with React Router, interactive state management, and live API data rendering for Practical 3.

## Highlights

- Multi-page navigation using React Router with Home, Projects, and Contact routes
- A controlled contact form with live character counting and real-time preview
- A theme toggle that switches between light and dark mode
- A custom 404 page for unknown routes
- A Projects page that fetches public GitHub repositories using the GitHub REST API with loading, error, retry, and search states

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
